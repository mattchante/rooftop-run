ROOFTOP RUN — HIGHRISE PLAYGROUND
Open rooftop-run.html in a modern browser. No installation, server or internet needed.

ROSTER
Patrick Star, German Shepherd, Mario, Darth Vader, Spider-Man. Press B to select a character; position is preserved.

CONTROLS
WASD move; Space jump; Shift sprint; hold C to crouch.
Mouse look; drag if pointer lock unavailable. Q/right click aim; left click/hold automatic fire; J single shot.
R reload; V swap shoulders; T respawn at helipad; H toggle controls; Esc pause/resume.

MODES
Free roam: explore two opposing lobbies, climbable roofs, construction platforms and service catwalks.
90-second range drill: hit all eight marked targets. Bullseyes earn 100 points; other target hits earn 50. The clock pauses with the game.

SETTINGS
Mouse sensitivity, three graphics presets, sound toggle and reduced motion.

This is an original stylized fan prototype with custom models and procedural materials, not a recreation using MW2 assets.
